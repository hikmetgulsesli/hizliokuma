## 2026-02-19 10:35 - US-002: Create DB query utilities for dashboard stats
- Created `lib/db/queries.ts` with reusable database query functions:
  - `getTotalUsers()`: Returns count of all users
  - `getActiveExercises()`: Returns count of exercises where is_active = 1
  - `getTotalCompletedExercises()`: Returns total count of user_exercise_results
  - `getDailyAverageMinutes()`: Returns average duration from exercise results
  - `getRecentActivities(limit)`: Returns recent exercise completions with user names
  - `getPopularExercises(limit)`: Returns exercises sorted by completion count
- Added TypeScript interfaces `RecentActivity` and `PopularExercise` for type safety
- All queries use parameterized queries for security
- Created comprehensive test suite in `__tests__/db-queries.test.ts` (18 tests)
- All 103 tests pass
- Typecheck passes
- Build passes
- PR created: https://github.com/hikmetgulsesli/hizliokuma/pull/14

**Learnings:**
- better-sqlite3 uses `.prepare().get()` for single row results and `.prepare().all()` for multiple rows
- LEFT JOIN is useful for getting exercises with zero completions
- SQL `AVG()` returns null when no rows match, so need to handle that case
- Use parameterized queries with `?` placeholders for security
