# Hızlı Okuma - React Admin Panel

Hızlı okuma egzersizleri uygulaması için React Next.js Admin Panel.

## Özellikler

- Blok Okuma egzersizi
- Grup Okuma egzersizi  
- Metin Arama egzersizi
- Gölgeleme egzersizi
- Ödül sistemi (Puan, Madalya, Streak)

## Teknolojiler

- Next.js 14+ (App Router)
- React 18+
- TypeScript
- shadcn/ui
- Tailwind CSS
- PostgreSQL

## Geliştirme

```bash
# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat
npm run dev

# Build al
npm run build

# Testleri çalıştır
npm test
```
