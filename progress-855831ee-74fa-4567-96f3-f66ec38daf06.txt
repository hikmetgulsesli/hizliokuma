## Codebase Patterns

### Project Structure
- Next.js 14.2.0 with App Router
- TypeScript with strict mode
- Tailwind CSS with shadcn/ui components
- Prisma ORM for database
- Jest + React Testing Library for tests
- Plus Jakarta Sans (heading) + Work Sans (body) font pair

### Component Patterns
- shadcn/ui components in `components/ui/`
- Admin-specific components in `components/admin-*.tsx`
- Pages under `app/admin/` route group
- Lucide React icons exclusively (no emojis)

### Styling Patterns
- Using CSS custom properties via Tailwind (HSL format)
- Dark mode support via `dark` class on html
- Custom font variables: `--font-heading`, `--font-body`
- Transition durations: 150-200ms for micro-interactions

### Testing Patterns
- Tests in `__tests__/` directory
- Mock `next/navigation` for pathname testing
- Mock `next/link` for rendering tests
- Use `data-testid` for element selection
