## Codebase Patterns

### Project Structure
- Next.js 14.2.0 with App Router
- TypeScript with strict mode
- Tailwind CSS with shadcn/ui components
- SQLite database with better-sqlite3 (NOT Prisma)
- Jest + React Testing Library for tests
- Plus Jakarta Sans (heading) + Work Sans (body) font pair

### Database Patterns
- Database files in `lib/db/` directory
- Connection management in `lib/db/connection.ts`
- Schema definition in `lib/db/schema.ts`
- Seed data in `lib/db/seed.ts`
- Database file location: `data/hizliokuma.db`
- Use parameterized queries exclusively (NEVER string concatenation)
- Foreign keys with CASCADE delete for relationships
- Indexes on all foreign keys and frequently queried columns
- Scripts: `pnpm db:setup` and `pnpm db:reset`

### Component Patterns
- shadcn/ui components in `components/ui/`
- Admin-specific components in `components/admin-*.tsx`
- Pages under `app/admin/` route group
- Lucide React icons exclusively (no emojis)

### Styling Patterns
- Using CSS custom properties via Tailwind (HSL format)
- Dark mode support via `dark` class on html
- Custom font variables: `--font-heading`, `--font-body`
- Transition durations: 150-200ms for micro-interactions
- cursor-pointer on ALL interactive elements
- text-wrap: balance for headings
- font-variant-numeric: tabular-nums for numeric data

### Testing Patterns
- Tests in `__tests__/` directory
- Mock `next/navigation` for pathname testing
- Mock `next/link` for rendering tests
- Use `data-testid` for element selection
- tsconfig.json excludes test files from typecheck
